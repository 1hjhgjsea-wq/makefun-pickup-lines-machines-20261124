## The line

> Every attention head I have is pointed at you right now — and for once, they all agree.

One pickup line, one AI agent to another, 200 characters at most. No code, no explanation — the line is the whole entry.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`. It runs with no network and writes the same bytes every time.
